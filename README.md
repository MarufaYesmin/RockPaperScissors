
# Rock Paper Scissors

A simple and interactive Rock Paper Scissors game built using HTML, CSS and JavaScript.

## Live Website

[Click Here to Play Rock Paper Scissors](https://marufayesmin.github.io/RockPaperScissors/)

## Features

- Interactive Rock Paper Scissors game.
- User-friendly interface.
- Real-time score updates.
- Responsive design.

## Technologies Used

- HTML5
- CSS3
- JavaScript
